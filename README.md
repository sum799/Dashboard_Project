# SumK9 Dashboard

SumK9 is a modern React dashboard built with Material UI and Vite.
It provides a clean, responsive experience for tracking performance, users, and business insights in a single workspace.

![preview](public/assets/images/aurora-free-preview.webp)

## Pages

- Dashboard
- Users
- Account
- Starter
- Error 404
- Login
- Sign up

## Quick start

- Recommended: `Node.js v20.x`
- **Install:** `npm i`
- **Start:** `npm run dev`
- **Build:** `npm run build`
- Open browser: `http://localhost:5005`
