# Providers

Documents for provider components that wrap application context and global services.

- `src/providers/AccountsProvider.tsx` — account-level context and helpers.
- `src/providers/BreakpointsProvider.tsx` — responsive breakpoint context.
- `src/providers/SettingsPanelProvider.tsx` — settings panel open/close state.
- `src/providers/SettingsProvider.tsx` — global app settings (font family, dark mode).
- `src/providers/ThemeProvider.tsx` — theme wrapper (documented in batch 1).
