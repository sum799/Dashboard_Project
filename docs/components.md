# Common Components

Short descriptions of common reusable components.

- `src/components/common/Logo.tsx` — renders the app logo and link to home.
- `src/components/common/SectionHeader.tsx` — small section header used across pages.
- `src/components/common/DashboardMenu.tsx` — legacy dashboard menu component.
- `src/components/common/PasswordTextField.tsx` — password input with visibility toggle.
- `src/components/common/CountrySelect.tsx` — country selector used in forms.
- `src/layouts/main-layout/common/ProfileMenu.tsx` — avatar and account menu (sign in/out, settings).
- `src/components/base/IconifyIcon.tsx` — icon wrapper used across the app.
- `src/components/loading/PageLoader.tsx` — centered page loading indicator.
- `src/components/pagination/CustomTablePaginationAction.tsx` — custom table pagination controls.
- `src/components/pagination/DataGridPagination.tsx` — DataGrid pagination adapter.
- `src/components/pagination/DataGridPaginationAction.tsx` — DataGrid action bridge.
- `src/components/pagination/TableLabelDisplayedRows.tsx` — pagination label renderer.
